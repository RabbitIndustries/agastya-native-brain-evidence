# Agastya India-First and Global-Frontier Claim Policy R1

## Why this policy exists

Rabbit Industries wants Agastya to become a globally recognized India-developed native foundation model. Strong claims should be built on evidence that survives independent scrutiny.

## What can be stated now

- Agastya AGI v01 is developed in India by Rabbit Industries Pvt Ltd.
- Rabbit Industries publishes company-generated evidence of random initialization and zero third-party weight ancestry for the canonical Native Brain lineage.
- Evidence Release R1 is publicly citable and cryptographically anchored.
- Independent third-party verification is pending.
- Same-suite external benchmark qualification is pending.

## What should not be stated as an established fact yet

- "India's first from-scratch foundation model."
- "India's first LLM trained from scratch."
- "World's first from-scratch foundation model."
- "World's best AI/AGI."
- Any external/global rank not produced by a directly comparable independent evaluation.

Earlier public Indian projects, including Sarvam, have already published from-scratch foundation-model claims. An unqualified India-first claim would therefore be contestable.

## Strong India-first verification target

Rabbit Industries may pursue a narrower, independently testable distinction such as:

"India's first independently verified, cryptographically provenanced native foundation-model lineage with zero third-party weight ancestry and independently verified tokenizer provenance."

This is a verification target, not a current established fact.

Before using it as a factual claim, require:
1. documented prior-art search;
2. precise claim definition;
3. independent evaluator PASS on lineage/tokenizer gates;
4. signed report;
5. dated DOI-backed evidence;
6. legal/public-claims review.

## Global-frontier target

Use:
"Designed and being evaluated for global frontier competitiveness."

Only use a best-in-world or numerical external-rank claim if a recognized, comparable evaluation actually supports it.
